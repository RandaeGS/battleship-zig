# Battleship (Zig + Raylib)
A simple, lightweight implementation of the classic Battleship game built using Zig and Raylib.

## Game Features
- Start Screen: Clean entry point to launch the game.
- Ship Placement Screen: Interactive setup phase for positioning your fleet.
- Main Gameplay Loop: Turn-based combat mechanics.
- Win/Loss Screens: Clear feedback upon victory or defeat.
- Game Reset: Quick option to restart and play again.

## Tech Stack
- Language: Zig 0.17.0
- Graphics Library: Raylib
